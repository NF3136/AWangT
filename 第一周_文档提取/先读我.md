# 华为文档提取器  1.3

本版在从 HDX 生成正文的过程中分卷，不先生成整本 Word。单份严格小于 10 MB，生成用户手册1、用户手册2等文件。

需要 Python 3.10 或更新版本。解压后在本文件所在目录打开 PowerShell：

```powershell
python -m pip install -r .\hdx_export_tools\requirements-word.txt
python .\hdx_export_tools\export_word.py --hdx "E:\资料\产品文档.hdx" --chapter "用户手册" --max-mb 10 --split-dir ".\输出\用户手册分卷" --split-prefix "用户手册" --merge-word-attachments --allow-large
```

将 HDX 路径改成自己电脑上的真实位置。运行前加 `--dry-run` 可只确认范围。输出文件夹必须尚不存在，重跑时换一个文件夹名。该命令包含全集处理许可，请自己确认范围后执行。

`--merge-word-attachments` 将目录里的 DOC/DOCX 正文编入连续分卷；附件单独起卷，保留原生样式。旧 DOC 自动转换需要安装 Microsoft Word 桌面版；只有 WPS 或网页 Word 不够。仅处理 HTML/DOCX 时不需要 Word 转换器。程序没有把所有格式的下载附件转换为正文；PDF、Excel 等仍保留原文件，超限时会报错停止。

输出 Word 和报告位于指定文件夹。移动时保持所有分卷和附件的相对目录。图片不降质；不能完整切开的超限内容会报错，不会删减后冒充成功。

验证：21 项小型测试通过；真实 iFC 29 项用 0.25 MB 上限试验生成 3 卷，自动检查通过。未执行真实用户手册全集，也未转换那份约 12.77 MB 原 DOC。附件原目录的缓存页码沿用原文件，不代表新分卷页码；复杂排版仍需在 Word 中验收。详细限制见 `hdx_export_tools/Word分卷使用说明.md`。

包内不含 Python、Word、HDX 或原始资料。分发工具时请交付整个文件夹或 ZIP，不要只复制一个脚本。

自检，不处理真实资料、不启动 Word：

```powershell
python -m unittest discover -s .\hdx_export_tools -p "test_*word.py" -q
```
