# 生成过程中分卷

版本 1.3：从 HDX 逐项生成正文，在转换过程中检查实际 DOCX 压缩体积并暂存小分卷。不会先生成一本完整的大 Word。转换结束后，只为这些小分卷补齐目录和跨卷链接，检查最终大小，再一次性发布结果文件夹。

## 执行命令

在交付包根目录打开 PowerShell，先安装依赖：

```powershell
python -m pip install -r .\hdx_export_tools\requirements-word.txt
```

指定自己的 HDX 路径：

```powershell
python .\hdx_export_tools\export_word.py --hdx "E:\资料\产品文档.hdx" --chapter "用户手册" --max-mb 10 --split-dir ".\输出\用户手册分卷" --split-prefix "用户手册" --merge-word-attachments --allow-large
```

若项目根目录或下一级文件夹只有一个 HDX，可以省略 `--hdx`。HDX 不必与脚本放在同一目录，只要指定正确路径。

- `--max-mb 10`：启用生成过程中分卷，每份严格小于 10,000,000 字节；默认预留 5% 空间。
- `--split-dir`：结果文件夹，必须尚不存在，避免混入旧分卷。每次重跑请换一个新文件夹名。
- `--split-prefix`：生成“用户手册1.docx、用户手册2.docx……”；文件数量由实际内容决定。
- `--merge-word-attachments`：将所选目录节点里的 DOC/DOCX 正文按原目录位置编入分卷。
- `--allow-large`：允许超过 200 个节点。全集可能耗时数分钟以上，请自行确认后运行。
- `--dry-run`：只确认范围，不转换 Word，也不启动附件转换。

分卷模式下 `--out` 只是兼容旧命令、用于推导默认目录和附件文件夹名；不生成该整本文件。`--overwrite` 不允许覆盖已有分卷目录。

## 原始 Word 附件如何处理

本包“用户手册”的 548 个节点包含 547 个 HTML 和一个原生 DOC：

`用户手册 > IMS容灾用户手册 > 容灾配置和调测指导书（VoBB）`

原文件为 `resources/redundancy/redundancy_word_vobb_nfv.doc`，约 12.77 MB。它来自 HDX 原文档包。

开启合并后：

1. DOCX 直接读取其原生文档包；旧 DOC 由本机安装的 Microsoft Word 桌面版转为 DOCX。只安装 WPS 或网页 Word 不能满足当前转换接口。纯 HTML 导出不需要安装 Word。
2. 转换器只读打开源文件，禁用宏和打开时的外部链接更新。转换后比较 Word 正文文本以及表格、内嵌图形、浮动图形、脚注、尾注数量；不同则报错停止。
3. 附件内容从原目录位置单独起卷，保留其原生样式、编号、表格和图片；仍按“用户手册N.docx”连续编号。后续 HTML 正文另起卷。
4. 原 DOC 不再作为一份超限附件随结果交付。不会把 DOC 的二进制字节当网页文字解码，也不采用纯文本复制来丢弃格式。

附件中的原目录和 REF/PAGEREF 域保留原缓存并锁定，避免更新时出现“找不到引用源”。附件原目录里的页码仍沿用原文件；正文内的超链接会建立跨卷目标，但不能把原目录页码当作新分卷页码。新分卷增加的目录可单独更新。

目前合并范围是目录本身指向的 DOC/DOCX。网页里额外下载链接引用的文件、PDF、Excel、压缩包等仍按原附件保留。任何未合并附件超过上限，默认整次发布停止并报出路径；不能声称所有格式都已转成正文。`--allow-large-attachments` 是显式放宽附件限制的旧兼容选项，本次 10 MB 交付要求不应使用。

## 内容与大小检查

- 逐项核对网页正文文本；去除网页导航，不删减技术内容。
- 按原顺序复制正文 XML；图片保留原字节，不降低清晰度。
- 优先在章节或小标题处分卷；整张表格、段落、跨段书签和复杂域不能随意截断。
- 如果单张图片、完整表格或不可拆开的内容已经超过限制，程序明确失败，不会压缩图片掩盖问题或输出超限文件。
- 每份最终 DOCX 按实际字节数检查，补齐目录和链接后再次确认。文本顺序、覆盖、图片数据、链接目标也会核对。
- 当前输出采取全部检查通过才发布的方式。转换中断或失败时，不将不完整结果发布为成品；报错后需修正并重跑。

## 结果与验收

```text
用户手册分卷/
  用户手册1.docx
  用户手册2.docx
  ...
  分卷报告.json
  阅读说明.txt
  用户手册_附件/  （只有其他未合并附件时）
```

保持全部分卷在同一文件夹，移动时一起移动。更新新目录后保存，须再次检查文件大小；预留空间不能保证任意后续编辑仍小于 10 MB。

自动检查通过不等于逐页排版验收。特别是旧 DOC 转换、分页、复杂表格和跨文件链接，需要在实际 Word 中抽查。当前版本通过小型合成测试，包括生成途中分卷、图片保真、链接、DOCX 附件跨卷及页眉/样式/编号保留；尚未执行真实 548 项全集或那份约 12.77 MB DOC 的转换验证。

环境自检（不读取真实 HDX，不启动 Word）：

```powershell
python -m unittest discover -s .\hdx_export_tools -p "test_*word.py" -q
```

`split_word.py` 仍保留为已有旧结果的维护工具，新版 `--max-mb` 导出不再调用整本生成后拆分的流程。
